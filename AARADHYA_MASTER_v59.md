   ```powershell
   $env:GEMINI_API_KEY="YOUR_KEY_HERE"
   ```
   *Add to `$PROFILE` for persistence.*
3. **Navigate to project root:**
   ```powershell
   cd "C:\Users\Aaradhya\OneDrive\Documents\0.Major Project"
   ```
4. **Run semantic extraction:**
   ```powershell
   graphify extract . --backend gemini
   ```
5. **Verify:**
   ```powershell
   start "C:\Users\Aaradhya\.graphify\global-tree.html"
   ```
   Nodes with `type: "semantic"` confirm success.
